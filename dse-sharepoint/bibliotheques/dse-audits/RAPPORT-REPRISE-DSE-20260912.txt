============================================================
5. INCIDENTS ET ENSEIGNEMENTS
============================================================

Incidents rencontres :
- Scripts IA contenant des guillemets manquants.
- Parametre ClientId ajoute inutilement.
- Parametre obligatoire $S incorrect.
- Plusieurs commandes fusionnees sur une meme ligne.
- Erreurs de pipeline avec -join.
- Noms de classes .NET supprimes pendant certains copier-coller.
- Blocage Windows Zone.Identifier apres telechargement.

Solutions validees :
- Privilegier un vrai fichier PS1 telechargeable.
- Executer Unblock-File apres telechargement si necessaire.
- Utiliser Connect-PnPOnline -Url $SiteUrl -Interactive, comme dans le script 001 valide.
- Verifier la syntaxe avec le parseur PowerShell avant execution.
- Commencer par une version LIGHT courte et testable.
- Ajouter les fonctions progressivement apres validation de chaque version.
