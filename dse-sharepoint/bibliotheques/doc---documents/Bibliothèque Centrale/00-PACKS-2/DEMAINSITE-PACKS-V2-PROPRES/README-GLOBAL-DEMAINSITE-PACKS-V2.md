# DemainSite Écosystème - Packs V2 propres

Version : V2.0.0  
Date : 2026-08-02

Ces packs remplacent les anciens packs V1 qui sont à archiver dans ARCHIVES/PACKS-V1.
Ils sont alignés avec les décisions validées :

- Bibliothèque Centrale comme source unique de vérité.
- Relation comme racine métier principale.
- Client = type de relation, pas forcément racine séparée.
- IDs automatiques, permanents, non modifiables, jamais recyclés.
- Anti-doublon obligatoire.
- Archivage au lieu de suppression réelle.
- Une action à la fois, validation de Pascal avant action sensible.
- SharePoint, Teams et automatisations construits progressivement.

## Utilisation recommandée

1. Déposer le ZIP global dans Bibliothèque Centrale > 00-PACKS-V2.
2. Décompresser si besoin.
3. Suivre PACK-00-V2-ORDRE-INSTALLATION-DEMAINSITE.
4. Installer ou créer les listes une par une seulement après contrôle.
5. Garder les anciens packs dans ARCHIVES/PACKS-V1.
