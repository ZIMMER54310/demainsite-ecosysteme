MISSION

Créer uniquement la liste SharePoint OBJ-ACT sur le site courant. Ne modifier aucune autre liste. Ne créer aucune ligne, aucune affectation et aucune donnée.

OBJECTIF

OBJ-ACT doit gérer :
OBJ → ACTEUR → ROLE → RESPONSABILITE → PERIODE

CONTROLES PREALABLES

Vérifier l’existence de : OBJ, OBJ-REF-50, OBJ-REL et OBJ-JRN.
Vérifier que OBJ contient ID-OBJ et que OBJ-REF-50 contient NOM-REF.
Vérifier que OBJ-ACT n’existe pas déjà.
En cas d’échec, ne créer aucune liste supplémentaire et produire quand même le rapport.

COLONNES

- ID-ACT : Texte, obligatoire, unique, indexé.
- OBJ : Lookup vers OBJ, champ ID-OBJ, obligatoire, indexé.
- ACTEUR-TYPE : Choix obligatoire : PERSONNE-M365 ; ENTREPRISE ; COMPTE ; EQUIPE ; IA ; AUTRE.
- ACTEUR-PERSONNE : Personne ou Groupe, une seule valeur.
- ACTEUR-ENTITE : Lookup vers OBJ, champ ID-OBJ, indexé.
- ROLE : Lookup vers OBJ-REF-50, champ NOM-REF, obligatoire, indexé.
- RESPONSABILITE : Lookup vers OBJ-REF-50, champ NOM-REF, obligatoire, indexé.
- ACTIF : Oui/Non, défaut Oui, indexé.
- RESPONSABLE-PRINCIPAL : Oui/Non, défaut Non, indexé.
- DATE-DEBUT : Date, indexée.
- DATE-FIN : Date, indexée.
- VERROUILLE : Oui/Non, défaut Non, indexé.
- CONTROLE-PASC-ARA : Oui/Non, défaut Non, indexé.
- SOURCE-AFFECTATION : Choix : MANUEL ; IMPORT ; APPLICATION ; IA ; WORKFLOW.
- ID-EXTERNE : Texte.
- DATE-DERNIER-CONTROLE : Date et heure.
- ANOMALIE-DETECTEE : Oui/Non, défaut Non, indexé.
- MOTIF-VERROUILLAGE : Texte multilignes.
- NOTES : Texte multilignes.

CONTROLE APRES CREATION

Relire le schéma de OBJ-ACT et vérifier explicitement :
- les 19 colonnes ;
- les cibles et champs d’affichage des 4 lookups ;
- les colonnes obligatoires ;
- l’unicité de ID-ACT ;
- les cinq valeurs par défaut Oui/Non ;
- les formats Date et Date et heure ;
- les 12 index ;
- l’absence de lignes.
Si l’ajout d’un index altère une cible de lookup, une obligation, une unicité ou une valeur par défaut, corriger OBJ-ACT uniquement puis relire le schéma.
Ne pas utiliser de contournement non supporté. Documenter toute limitation résiduelle.

ANALYSE IA SHAREPOINT SANS MODIFICATION

Après création :
- analyser la structure ;
- identifier les risques ;
- identifier les colonnes potentiellement manquantes ;
- vérifier la compatibilité avec OBJ, OBJ-REL et OBJ-JRN ;
- évaluer la compatibilité avec le pilote Application DemainSite ;
- ne créer aucune automatisation et n’appliquer aucune autre modification.

RAPPORT OBLIGATOIRE

Créer Rapport_creation_OBJ_ACT.txt même en cas d’échec, avec :
- Date ;
- Liste créée ;
- Colonnes créées ;
- Lookups créés ;
- Index créés et non confirmés ;
- Contraintes appliquées ;
- Conseils IA SharePoint ;
- Limitations détectées ;
- Erreurs éventuelles ;
- Résultat final.

Créer aussi Prompt_reutilisable_creation_OBJ_ACT.txt contenant ce prompt. Proposer les deux fichiers en téléchargement.
