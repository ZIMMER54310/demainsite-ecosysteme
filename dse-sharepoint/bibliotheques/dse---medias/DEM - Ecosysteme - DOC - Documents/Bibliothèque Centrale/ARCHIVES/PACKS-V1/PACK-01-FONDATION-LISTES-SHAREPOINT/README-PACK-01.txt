PACK-01 - FONDATION LISTES SHAREPOINT

But : créer automatiquement les listes principales de la Bibliothèque Centrale dans SharePoint.

Listes prévues :
Relations, Clients, Projets, Sites, Domaines, Pages, Medias, Documents, Utilisateurs, Equipes_Teams, Canaux_Teams, SharePoint, Procedures.

Installation :
1. Télécharger ce pack.
2. Décompresser localement.
3. Ouvrir PowerShell dans le dossier.
4. Exécuter : .\DEMAIN_SITE_CREATE_LISTS.ps1
5. Se connecter avec le compte Microsoft 365 autorisé.
6. Revenir dans SharePoint > Contenu du site pour vérifier.

Site cible : https://blogssite.sharepoint.com/sites/Bibliotheque
