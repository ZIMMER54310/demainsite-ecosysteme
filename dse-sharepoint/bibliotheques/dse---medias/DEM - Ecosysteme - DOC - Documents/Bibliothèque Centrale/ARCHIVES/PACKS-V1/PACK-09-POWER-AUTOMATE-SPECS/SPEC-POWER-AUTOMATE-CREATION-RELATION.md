# Flux Power Automate - Création Relation V1
Déclencheur : nouvel élément dans Relations.
Contrôles : champs obligatoires, doublons nom/email/téléphone/domaine.
Actions : générer ID si vide, journaliser, calculer score, préparer client lié.
Sécurité : ne pas créer Teams, ne pas inviter de membres, ne pas modifier les droits automatiquement.
