# DSE-VUES-COMMUNES-A-Z-V1.0

## Objectif

Eviter une liste Villes trop lourde en creant des vues SharePoint par ordre alphabetique.

Le script ajoute une colonne :

```text
Lettre Commune
```

Puis il cree les vues :

```text
Communes - Toutes A-Z
Communes - A
Communes - B
...
Communes - Z
Communes - Autres
```

## Utilisation

Double-cliquer sur :

```text
LANCER-VUES-COMMUNES-A-Z.bat
```

Puis ecrire :

```text
OUI
```

## Audit sans modification

Double-cliquer sur :

```text
LANCER-AUDIT-VUES-COMMUNES-A-Z.bat
```

## Regle DemainSite

Suppression automatique = NON.
Creation de vues = OUI.
Journalisation = OUI.
