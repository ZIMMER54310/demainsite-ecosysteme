# Règle officielle des IDs

- L'utilisateur ne saisit jamais l'ID manuellement.
- Le Super Administrateur ne modifie jamais l'ID.
- Un ID n'est jamais recyclé.
- Un objet supprimé visuellement doit être archivé, suspendu ou placé en corbeille métier.
- La numérotation réelle pourra être automatisée plus tard par Power Automate ou script validé.
