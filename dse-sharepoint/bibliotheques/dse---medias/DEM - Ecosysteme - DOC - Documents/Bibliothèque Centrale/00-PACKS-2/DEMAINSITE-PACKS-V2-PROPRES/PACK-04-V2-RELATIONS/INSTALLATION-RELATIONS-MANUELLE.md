# Installation manuelle de la liste Relations

1. Aller dans Contenu du site.
2. Ouvrir ou créer la liste Relations.
3. Renommer la colonne Titre en Nom_Relation si nécessaire.
4. Ajouter les colonnes une par une selon SCHEMA-LISTE-RELATIONS-V2.csv.
5. Ne pas créer ID_Relation manuellement pour les utilisateurs finaux : le champ existe mais sera alimenté plus tard automatiquement.
6. Contrôler avec 1 fiche test seulement avant import massif.
