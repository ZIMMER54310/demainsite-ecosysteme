# Checklist globale V2

1. Archiver les anciens packs dans ARCHIVES/PACKS-V1.
2. Déposer les nouveaux packs V2 dans 00-PACKS-V2.
3. Ne pas lancer de script automatique au départ.
4. Créer ou vérifier les listes une par une.
5. Contrôler chaque étape dans Contenu du site.
6. Valider chaque liste avant de passer à la suivante.
